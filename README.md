## 📖 About

Kids-CodePlay is an educational web application designed for children aged **5–13 years**. Instead of introducing programming through complex syntax, the platform teaches computational thinking using colorful visual blocks, interactive challenges, animated characters, and reward-based progression.

The application follows the **Learning by Playing** philosophy, allowing children to solve coding puzzles while naturally developing logical thinking, sequencing, pattern recognition, problem-solving, and creativity.

## 🎮 Learning Journey

### 👋 Welcome Screen
A colorful onboarding experience introducing children to the world of coding through friendly illustrations and motivational messages.

### 🏠 Home Dashboard
Displays available lessons, coding quests, earned stars, and learning progress.

### 🧩 Interactive Coding Game
Children solve puzzles by arranging visual command blocks such as:

- Move Forward
- Turn Left
- Turn Right
- Repeat

The objective is to guide the character through different challenges while learning logical thinking.

### 🗺️ Adventure Map
A progression system where learners unlock new levels, collect stars, and discover new coding missions.

### 👤 Student Profile
Track achievements, badges, completed lessons, hints used, and overall learning statistics.

### 🎉 Reward System
Celebrate every achievement with animations, confetti, badges, and motivational feedback.

## 🌟 Why Kids-CodePlay?

Children learn by exploring, solving puzzles, earning rewards, and progressing through exciting coding quests without feeling overwhelmed by complex programming syntax.
